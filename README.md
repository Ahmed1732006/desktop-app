# In The Void — محاسبة التكاليف (Desktop)

نسخة Windows من ملف HTML المرفوع، تعمل داخل نافذة تطبيق مستقلة باستخدام Electron.

## تشغيل محلي

```bash
npm install
npm start
```

## إنشاء Installer لويندوز

```bash
npm install
npm run dist
```

سيظهر ملف التثبيت داخل مجلد `release/`.

## GitHub Actions

ارفع المشروع إلى GitHub ثم شغّل:

`Actions → Build Windows App → Run workflow`

أو أنشئ Tag يبدأ بـ `v` مثل `v1.0.0` ليتم البناء تلقائيًا.

## ملاحظات

- ملف الموقع الأصلي موجود باسم `index.html` ولم يتم إعادة كتابة محتواه.
- التطبيق يمنع التنقل الداخلي إلى صفحات HTTP/HTTPS داخل نافذته ويفتح الروابط الخارجية في المتصفح الافتراضي.
- الموقع نفسه يحتوي على موارد خارجية موجودة أصلًا في النسخة المرفوعة، مثل Google Fonts وبعض مكتبات PDF التي يتم تحميلها عند الحاجة؛ لذلك ليست كل وظائف الموارد الخارجية Offline بنسبة 100%.
